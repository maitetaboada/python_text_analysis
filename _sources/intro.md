# Python Text Analysis

# Course description
The course introduces basic concepts and tools for text analysis using the python programming language. It will address data capture and manipulation, data cleaning and preprocessing, and text analysis for linguistics and other social sciences.

# Course objectives
At the end of the course, students will have learnt the basic aspects of python programming. They will understand how to process language data for various analyses.

More specifically, students will:

Learn core concepts of programming (variables, functions, objects).
Learn to install and use basic packages for text analysis (NLTK, spacy).
Be able to collect and store a dataset using existing python packages.
Clean and normalize language data.
Perform natural language processing analysis on language data.

# Components of the course
The course consists of one hour of class time every week, during which we will mostly work on labs, practice exercises and group work.

Attendance is mandatory to pass the course, unless there are extenuating circumstances. You are also expected to be actively engaged in class discussions and activities. You can have up to 2 unexcused absences in the semester.
Weekly reflections need to be completed every week. This is a short discussion or reflection on what you learned during the week.
Labs are completed every week and graded on completion, showing a good effort.
Assignments expand on the labs and are an opportunity to analyze data the students are interested in. They can be completed in groups of maximum 2 students.
All the things you have to submit (reflections, labs, assignments) have a soft deadline (Friday, 11:59 pm) and a hard deadline (Sunday, 11:59 pm). You are supposed to submit them by Friday, especially if you need our help, as we cannot answer questions over the weekend. You can, however, submit on Sunday without a late penalty. We just won't be able to provide any answers if you get stuck on the weekend. Anything submitted after Sunday 11:59 receives a grade of 0.
